☁️ Pengenalan VPS & Cloud

Mengenal empat jenis layanan hosting dan server beserta fungsi serta karakteristiknya.

🌐

Shared Hosting

Shared Hosting adalah layanan hosting di mana beberapa website menggunakan satu server dan berbagi sumber daya seperti CPU, RAM, dan penyimpanan. Layanan ini cocok untuk website pribadi atau bisnis kecil karena harganya lebih ekonomis.

Hemat Biaya
🖥️

Dedicated Server

Dedicated Server adalah layanan server fisik yang seluruh sumber dayanya digunakan oleh satu pengguna. Memberikan performa, keamanan, dan kontrol lebih maksimal, cocok untuk website atau aplikasi dengan trafik tinggi.

Performa Maksimal
🚀

Amazon Lightsail

Amazon Lightsail adalah layanan cloud dari AWS yang menyediakan VPS dengan konfigurasi sederhana. Pengguna dapat membuat server virtual dengan paket harga yang lebih mudah diprediksi. Cocok untuk pemula dan proyek skala kecil hingga menengah.

Mudah Digunakan
⚡

Amazon EC2

Amazon EC2 (Elastic Compute Cloud) adalah layanan komputasi cloud dari AWS yang menyediakan server virtual dengan konfigurasi fleksibel. Pengguna dapat mengatur kapasitas CPU, RAM, penyimpanan, dan jaringan sesuai kebutuhan aplikasi.
